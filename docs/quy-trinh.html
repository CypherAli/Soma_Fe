Soma 3D · tài liệu vận hành

Tài nguyên đi từ đâu tới màn hình

Toàn bộ dự án chạy trên bốn đường ống. Trang này nói rõ mỗi thứ trên web đến từ nguồn nào, qua bước xử lý gì, và bạn phải gõ lệnh nào để làm lại — theo đúng thứ tự.

01

Bản đồ một trang

Đọc từ trái sang phải: dữ liệu thô nằm ngoài dự án, qua bước xử lý thành tệp trong public/, rồi trang web đọc các tệp đó.

Xử lý (chạy một lần)

  • Chụp ảnh đại diệnrender từ chính mô hình

Trên web

  • public/models/130 tệp .glb người + 3 sọ thú y

Nguồn→Xử lý→Tệp trong repo→Trang web đọc
Điều cần nhớ: tệp nguồn (Startup.blend, PDF) không nằm trong repo vì quá nặng và vướng bản quyền. Repo chỉ chứa kết quả đã xử lý cộng với script để làm lại. Ai clone về cũng dựng lại được, miễn có tệp nguồn.

03

Bốn đường ống

Mỗi đường ống độc lập. Muốn thêm thứ gì lên web, tìm đúng đường ống của nó rồi làm theo các bước.

A · Mô hình 3D

Blender nặng nhất

Dùng khi muốn thêm một mô hình mới, ví dụ "vùng hố nách" hay "khớp cổ chân".

  1. Xem trong tệp nguồn có gì

    In ra tên và toạ độ mọi vật thể để biết mình sẽ cắt cái gì.

    # đặt đường dẫn Blender một lần cho cả phiên
BLENDER="C:/Program Files/Blender Foundation/Blender 5.1/blender.exe"

"$BLENDER" --background "Startup.blend" \
  --python scripts/blender/dump_objects.py
  2. Khai báo hộp cắt

    Thêm một mục vào scripts/blender/region_config.py: toạ độ hộp, từ khoá giữ lại, từ khoá loại bỏ.

  3. Xuất ra .glb 
    "$BLENDER" --background "Startup.blend" \
  --python scripts/blender/export_region.py -- ten_vung public/models/ten_vung.glb
  4. Giảm nhẹ nếu quá 12 MB 
    "$BLENDER" --background \
  --python scripts/blender/decimate_glb.py -- vao.glb ra.glb
  5. Chụp ảnh đại diện

    Ảnh chụp từ chính mô hình, không lấy ảnh ngoài.

    node scripts/render-thumbnails.mjs
node scripts/optimize-thumbnails.mjs
  6. Khai báo scene và đặt nhãn

    Thêm vào src/lib/scenes/*.ts: tên ba thứ tiếng, tên Latin, ghi chú, và meshName đúng như trong tệp .glb.

Kiểm trước khi tin 
npm run verify:scenes        # nhãn phải trỏ tới mesh có thật
node scripts/verify-layers.mjs
npm run verify:models        # cảnh báo mô hình quá nặng

Mô hình thú y tải từ ngoài đi đường riêng, một lệnh là xong — script tự giảm lưới, nén Draco, từ chối giấy phép ND, rồi in ra đoạn mã cần dán:

node scripts/vet/import-vet-model.mjs duong-dan.glb   --species dog --slug dog-skull   --license "CC BY 4.0" --by "Tên tác giả" --url https://zenodo.org/records/...

B · Nội dung và hình bệnh lý

Python PDF

Dùng khi thêm một bệnh mới hoặc thêm hình minh hoạ trích từ giáo trình.

  1. Rút chữ từ PDF
    python scripts/kb/ocr_pdf.py
  2. Cắt hình trong sách
    python scripts/kb/build_atlas_shots.py
python scripts/kb/mask_atlas_labels.py   # che nhãn để ra đề
  3. Chụp vị trí tổn thương trên mô hình 3D
    node scripts/render_all_lesions.mjs
  4. Nạp vào cơ sở dữ liệu

    Trong thư mục ../soma_be:

    npm run db:seed
Kiểm trước khi tin 
npm run verify:lesions   # mốc tổn thương phải trỏ đúng mesh

04

Chạy dự án ở máy

Hai phần chạy song song: web ở cổng 3000, API ở cổng 3001.

# --- web (thư mục Soma_Fe) ---
npm install
npm run dev

# --- API + cơ sở dữ liệu (thư mục soma_be) ---
npm install
npm run prisma:generate
npm run prisma:deploy    # tạo bảng
npm run db:seed          # nạp bệnh lý và cấu trúc
npm run start:dev
TệpKhoáDùng để

05

Trước khi nộp hoặc đưa lên mạng

Chạy hết một lượt. Mỗi lệnh kiểm một loại sai khác nhau, và tất cả đều phải xanh.

npx tsc --noEmit && npx eslint src scripts

npm run verify:scenes         # 1310 nhãn ↔ mesh thật
node scripts/verify-layers.mjs
npm run verify:models
npm run verify:lesions

npm run test:vet-kb           # kho thú y
npm run test:site-kb          # kho hiểu biết về web
npm run test:gestures         # cử chỉ tay

npm run build

Đưa lên mạng bằng Render: web chạy npm run build rồi npm start; API chạy npm run build rồi npm run start:prod. Sau lần deploy đầu, chạy prisma:deploy và db:seed một lần trên máy chủ.

06

Ba quy tắc chi phối mọi thứ

  • Không bịa Thư viện không có thì nói chưa có. Áp dụng cho cả trợ lý lẫn nội dung trang — đây là nội dung y khoa.
  • Nhãn nào cũng phải kiểm được Một hotspot trỏ tới mesh không tồn tại là lỗi chặn, không phải chuyện nhỏ. Vì thế mới có verify:scenes.
  • Tài nguyên ngoài phải nói được nguồn gốc Mỗi tệp lấy từ nơi khác đều ghi rõ giấy phép và người làm, hiện ngay trên trang dùng nó.
Bản tra cứu lệnh ngắn gọn: docs/QUY-TRINH.md trong repo.
